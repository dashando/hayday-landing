Официальный промо-лендинг для казуальной мобильной игры **Hay Day** (Supercell).

## 🚀 О проекте
Индивидуальный проект по дисциплине «Информатика» (Лабораторные работы №4 и №5).
- **Студент:** Соколова Д. А. (гр. 4618, ГУАП)

- **Технологии:** HTML5, CSS3, Vanilla JS, Git, GitHub Pages, AI Agent.

3.  — ветка доработки пользовательского интерфейса, навигации и документации.
